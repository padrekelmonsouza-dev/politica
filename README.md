# Kelmon: Sua Voz em SP

Crie uma Landing Page moderna, responsiva e de alto impacto para o Padre Kelmon, candidato a Deputado Federal por São Paulo.

Antes de iniciar o desenvolvimento:

1. Acesse o perfil oficial do Instagram:

https://www.instagram.com/pekelmon/

2. Analise todo o conteúdo disponível publicamente:

- Biografia

- Fotos

- Vídeos

- Reels

- Destaques

- Identidade visual

- Cores predominantes

- Tipografia utilizada

- Linguagem de comunicação

- Bandeiras defendidas

- História

- Missão

- Valores

- Publicações mais relevantes

- Fotos institucionais

- Fotos com apoiadores

- Fotos em eventos

- Conteúdo político

Utilize essas informações para criar uma landing page profissional.

Objetivo da página:

Captar apoiadores, apresentar a trajetória do Padre Kelmon e incentivar o cadastro de voluntários e futuros eleitores.

A identidade visual deve transmitir:

- Conservadorismo

- Patriotismo

- Credibilidade

- Fé Cristã

- Elegância

- Modernidade

- Autoridade

Paleta sugerida:

- Azul escuro

- Verde

- Branco

- Dourado como cor de destaque

Layout Premium.

Recursos técnicos:

- Next.js

- React

- TypeScript

- Tailwind CSS

- Framer Motion

- Componentes reutilizáveis

- SEO completo

- Open Graph

- Schema.org

- Performance acima de 95 no Lighthouse

- Responsivo para celular, tablet e desktop

- Código limpo

- Acessibilidade (WCAG)

- Lazy Loading

- Otimização de imagens

- Dark Mode opcional

Importante:

- Não invente informações biográficas.

- Utilize apenas conteúdo disponível publicamente e atribua corretamente as informações quando necessário.

- Caso algum dado não esteja disponível, deixe a estrutura preparada com um placeholder indicando que o conteúdo deverá ser preenchido posteriormente.

- Produza um resultado com aparência de campanha política profissional, semelhante aos melhores sites de campanhas eleitorais modernas.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
